# ⚡ Quick Start — ZEE5 + Auto Background Mode

Follow these steps to get your bot running **with ZEE5 integration**, working **automatically in the background 24/7**.

---

## Step 1: Clone & Setup (5 minutes)

### On Your Local Machine

```bash
# Navigate to your workspace
cd ~/Projects

# Clone the bot
git clone https://github.com/YOUR_USERNAME/fifa-shorts-bot.git
cd fifa-shorts-bot

# Run setup script (installs all dependencies)
bash setup.sh

# Activate virtual environment
source .venv/bin/activate
```

---

## Step 2: Configure Credentials (10 minutes)

### 2.1 Copy the template
```bash
cp .env.example .env
```

### 2.2 Edit `.env` file
```bash
nano .env
```

Fill in these sections:

#### A) YouTube (for uploading Shorts)
```
YOUTUBE_CLIENT_ID=<from Google Cloud Console>
YOUTUBE_CLIENT_SECRET=<from Google Cloud Console>
YOUTUBE_REFRESH_TOKEN=<auto-generated on first run>
```

How to get YouTube credentials:
1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create new project
3. Enable **YouTube Data API v3**
4. Create **OAuth 2.0 Client ID** (Desktop)
5. Download JSON → save as `config/youtube_client_secrets.json`
6. First time you run the bot, it will open a browser for consent

#### B) Instagram (for uploading Reels)
```
INSTAGRAM_ACCESS_TOKEN=<your token>
INSTAGRAM_BUSINESS_ACCOUNT_ID=<your account ID>
INSTAGRAM_MEDIA_HOST_URL=https://your-server.com/media/
```

How to get Instagram credentials:
1. Create [Facebook Developer App](https://developers.facebook.com/)
2. Add Instagram Graph API product
3. Generate long-lived access token
4. Find your Business Account ID via Graph API Explorer

#### C) ⭐ ZEE5 (India-focused sports content)
```
ZEE5_EMAIL=your_zee5_email@gmail.com
ZEE5_PASSWORD=your_zee5_password
ENABLE_ZEE5_CRAWL=true
ENABLE_ZEE5_UPLOAD=false
```

How to set up ZEE5:
1. Create account at [zee5.com](https://zee5.com)
2. Add your email/password to `.env`
3. Bot will auto-login and crawl FIFA content

#### D) AI Captions (optional but recommended)
```
OPENAI_API_KEY=sk-...
```

#### E) Scheduling (adjust these later if needed)
```
CRAWL_INTERVAL_MINUTES=30          # Every 30 min, discover new content
MAX_SHORTS_PER_RUN=3               # Produce max 3 shorts per run
TIMEZONE=Asia/Kolkata              # Change to your timezone
```

#### F) Other Important Settings
```
ENABLE_YOUTUBE_UPLOAD=true
ENABLE_INSTAGRAM_UPLOAD=true
ENABLE_ZEE5_CRAWL=true
DRY_RUN=false                      # Set to true to test without uploading
```

### 2.3 Save the file
- Press `Ctrl+X` → `Y` → `Enter` (in nano)

## Step 4: Run the Bot (Choose One Method)

### Method A: Manual (Recommended First Time)
```bash
python main.py --once
```

This runs once, uploads everything, then stops. Good for testing.

### Method B: Auto Background (Linux/Mac)
```bash
nohup python main.py > logs/nohup.log 2>&1 &
```

Bot runs in background, you can close terminal. Check status:
```bash
ps aux | grep python        # see if running
tail -f logs/nohup.log      # view live logs
kill %1                     # stop it if needed
```

### Method C: Scheduled Service (Linux - Best for 24/7)

Create service file:
```bash
sudo nano /etc/systemd/system/fifa-shorts-bot.service
```

Paste this:
```ini
[Unit]
Description=FIFA 2026 Shorts Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/fifa-shorts-bot
ExecStart=/home/ubuntu/fifa-shorts-bot/.venv/bin/python main.py
Restart=always
RestartSec=60
StandardOutput=append:/home/ubuntu/fifa-shorts-bot/logs/service.log
StandardError=append:/home/ubuntu/fifa-shorts-bot/logs/service.log

[Install]
WantedBy=multi-user.target
```

Then:
```bash
sudo systemctl daemon-reload
sudo systemctl enable fifa-shorts-bot
sudo systemctl start fifa-shorts-bot
sudo systemctl status fifa-shorts-bot
```

Check logs:
```bash
sudo journalctl -fu fifa-shorts-bot -n 50
```

## Step 5: Deploy to Free Cloud Server (20 minutes)

Choose **ONE** platform:

### Option A: Railway (Easiest) ✅ RECOMMENDED

1. **Create account** at [railway.app](https://railway.app) (use GitHub login)
2. **Push code to GitHub**
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/fifa-shorts-bot.git
   git branch -M main
   git push -u origin main
   ```
3. **Create Procfile** (tell Railway what to run):
   ```bash
   echo "worker: python main.py" > Procfile
   git add Procfile && git commit -m "add Railway config" && git push
   ```
4. **In Railway dashboard:**
   - Click "New Project" → "Deploy from GitHub"
   - Select your repo
   - Click "Deploy"
5. **Add Environment Variables:**
   - Go to project → "Variables"
   - Add all your `.env` settings (copy-paste)
6. **Done!** Railway will run your bot 24/7 (free tier: 500 hrs/month)

Check logs in Railway dashboard → Deployments → View Logs

### Option B: Google Cloud Run (Cheapest Running Costs)

```bash
# Login to Google Cloud
gcloud auth login
gcloud config set project fifa-shorts-bot

# Create Dockerfile
cat > Dockerfile << 'EOF'
FROM python:3.11-slim
WORKDIR /app
COPY . .
RUN apt-get update && apt-get install -y ffmpeg imagemagick chromium && rm -rf /var/lib/apt/lists/*
RUN pip install -r requirements.txt
CMD ["python", "main.py"]
EOF

# Deploy
gcloud run deploy fifa-shorts-bot \
  --source . \
  --region us-central1 \
  --memory 2Gi \
  --set-env-vars YOUTUBE_CLIENT_ID=YOUR_VALUE,YOUTUBE_CLIENT_SECRET=YOUR_VALUE,...
```

## Step 6: Monitor Your Bot (Daily)

### Check if it's running

**On your local machine:**
```bash
ps aux | grep python
tail -f logs/bot.log
```

**On Railway:**
- Dashboard → Deployments → View Logs

**On Cloud Run:**
```bash
gcloud run logs read fifa-shorts-bot --follow
```

**On AWS Lightsail:**
```bash
sudo journalctl -fu fifa-shorts-bot -n 20
```

### What to look for in logs
✅ Good:
```
Discovered 45 candidates
Downloaded: video_name.mp4
Exported short: short_20260614_120530.mp4
Uploaded to YouTube: https://www.youtube.com/shorts/...
Instagram Reel live: media_id=...
```

❌ Bad:
```
Download failed, skipping
Auth token expired
API rate limit exceeded
```

## Step 7: Manage & Optimize

### To run different modes:

```bash
# Discover only (preview what it finds)
python main.py --crawl-only

# Run once and upload
python main.py --once

# Test without uploading
python main.py --once --dry-run

# Run continuously (default)
python main.py
```

### To adjust frequency:
Edit `.env`:
```
CRAWL_INTERVAL_MINUTES=60    # Every hour instead of 30 min
MAX_SHORTS_PER_RUN=1         # Only 1 short per run (safer)
```

Then restart the bot.

### To enable more sources:
Edit `.env`:
```
ENABLE_ZEE5_CRAWL=true       # ZEE5 content
ENABLE_YOUTUBE_UPLOAD=true   # Upload to YouTube Shorts
ENABLE_INSTAGRAM_UPLOAD=true # Upload to Instagram Reels
ENABLE_AI_CAPTIONS=true      # AI-generated titles
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| "ModuleNotFoundError" | Run `pip install -r requirements.txt` |
| "ffmpeg not found" | Run `bash setup.sh` or `apt-get install ffmpeg` |
| "YouTube auth failed" | Check `config/youtube_client_secrets.json` exists |
| "Instagram upload fails" | Verify `INSTAGRAM_MEDIA_HOST_URL` is public & accessible |
| "ZEE5 login error" | Check email/password in `.env` (special chars? escape them) |
| "Bot not running" | Check: `ps aux \| grep python` or systemctl status |
| "Logs show nothing" | Run `python main.py --once --dry-run` to see output |
